# OpsPilot AI v1.0.0-local

This initial portfolio release packages the existing local Northstar Supply application. It adds a Windows setup/start/stop/status workflow, an isolated installation path, reviewed presentation assets, and a GitHub Actions definition for locked dependencies, real pgvector integration and the production frontend build.

The release includes historical business analytics, verified keyword and vector knowledge retrieval, deterministic operational investigations, evidence-bound task and escalation proposals, separate approval and execution, audit records and execution receipts.

Install locally with Docker Desktop and uv. Setup generates private accounts and fetches the pinned public MiniLM encoder. No paid AI API or inference service is needed. Optional Ollama and the legacy agent are experimental. [Install](QUICK_START.md) · [Demo](DEMO_GUIDE.md) · [Acceptance evidence](STAGE8_REPORT.md)

The intended environment is a single loopback Windows workspace with synthetic data. The limited accessibility, security and performance checks are reported at their measured scope. This version does not establish shared production deployment or a service-level agreement.
